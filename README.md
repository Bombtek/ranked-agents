# Ranked Agents
Tier list of AI agent and automation tools. Next.js App Router + Tailwind, fully static.

Live at https://rankedagents.dev (the old https://ranked-agents.vercel.app host 308-redirects there via `next.config.mjs`).

Edit data in `data/tools.ts`, `data/rankings.ts`, `data/releases.ts`. Never invent pricing — use "See site".
Set `NEXT_PUBLIC_SITE_URL` to override the canonical URL (defaults to `https://rankedagents.dev` in `lib/site.ts`).
